# Multimodal Fusion — Research Scratchpad (legacy)

Snapshot of the original `mma-project` repo (Sep 2025) — the experimental scratchpad that the polished `multimodal-fusion` (parent directory) grew out of.

Preserved here for the research artifacts:

- `question_bank.json` — curated evaluation questions
- `qa_results/` — early QA session traces against test PDFs
- `Early Fusion/` and `Evalution/` — initial standalone implementations of the fusion modes
- `image_embedder.py`, `test_image_embedder.py` — image embedding experiments

Status: frozen, kept for traceability. Run the parent directory's polished pipeline instead.
